# V1 手工验收清单

## 准备
1. 启动应用：`npm start`
2. 确认未出现“试用期已过”禁用页面。

## 用例 1：新增用户与持久化
1. 新增用户 `A`，再新增用户 `B`。
2. 关闭应用并重新启动。
3. 预期：
   - `A/B` 仍在用户列表中。
   - 可正常切换用户。

## 用例 2：标准格式解析
1. 切换到用户 `A`。
2. 输入：`14.21.13～各20`，点击识别并确认。
3. 预期：
   - `14/21/13` 各 +20。
   - 用户 `A` 总计 +60。

## 用例 3：分隔符兼容解析
1. 继续在用户 `A` 输入：`14 21 13~各20`，点击识别并确认。
2. 预期：
   - `14/21/13` 再各 +20。
   - 用户 `A` 总计再 +60。

## 用例 4：删除原始记录回滚
1. 在原始记录区删除刚才一条输入记录。
2. 预期：
   - 对应号码累计值减少该条记录贡献。
   - 用户总计同步回滚。
   - 不出现负值。

## 用例 5：汇总模式
1. 给用户 `B` 也录入一条消息（如：`01.02.03～各10`）。
2. 点击“所有网友消息汇总”。
3. 预期：
   - 汇总排序区域出现 `A+B` 的累计结果。
   - 标题总计值等于所有用户 `totalCount` 之和。

## 用例 6：异常输入
1. 输入 `50.01～各20` 或 `14.21.13～各0`。
2. 预期：
   - 识别失败并提示错误。
   - 不写入用户数据。
