# AI 消息统计 用户使用说明书（V6.0.0）

适用对象：首次安装的软件用户、录入人员、店员、运营同事、管理员。  
适用版本：`v6.0.0`  
文档目标：让用户从“第一次打开软件”到“每天稳定使用、导出、排查问题”都能照着操作。

---

## 1. 这是什么软件

这是一款本地离线的桌面统计工具，核心用途是：

1. 录入客户发来的原始消息。
2. 自动解析消息中的号码、生肖、属性词、区域信息。
3. 把结果按客户、按区域、按号码、按原始消息进行统计展示。
4. 按中奖号计算各区域结果汇总。
5. 导出 Word / Excel 结算文档。

软件主模块名称为：`AI 消息统计`。  
你平时最常用的几个入口是：

1. `消息识别`
2. `复制当前范围`
3. `导出当前范围`
4. `数据上报`
5. `设置`

---

## 2. 使用前要准备什么

正式使用前，请确认你已经拿到下面几样东西：

1. 安装包。
2. 模块访问密码。
3. 授权方式。
说明：可能是授权 U 盘，也可能是离线授权码 / `license.dat` 文件。

如果缺少上面任意一项，不建议直接开始安装。

---

## 3. 安装与首次启动

### 3.1 Windows 安装

1. 双击安装包。
2. 按安装向导一路下一步。
3. 安装完成后，桌面会出现软件图标。
4. 如果你使用的是 U 盘授权，先插好授权 U 盘。
5. 再启动软件。

### 3.2 macOS 安装

1. 打开 `.dmg`。
2. 将应用拖入 `Applications`。
3. 如果是第一次运行，系统可能要求确认来源。
4. 如果使用 U 盘授权，先插好授权 U 盘再打开软件。

### 3.3 第一次打开后会看到什么

正常情况下，首次打开会进入密码页。  
输入正确密码后，进入 `AI 消息统计` 主界面。

如果打开后看到的是“授权已失效 / 需要有效授权”的拦截页：

1. 先不要反复重开。
2. 优先检查授权 U 盘或离线授权文件。
3. 再看本说明书第 14 章“授权管理”。

## 4. 登录与模块入口

启动软件后会要求输入访问密码。

1. 输入正确密码后进入 `AI 消息统计`。
2. 如果密码错误，界面会提示重试。

## 5. 正式使用前，先理解主界面

进入 `AI 消息统计` 后，主界面从左到右大致分成 4 个区域。

### 5.1 顶部菜单

顶部按钮分别是：

1. `消息识别`
作用：打开录入弹窗，把原始消息录入系统。

2. `复制当前范围`
作用：把当前统计范围生成的结果文本复制到剪贴板。

3. `导出当前范围`
作用：导出当前范围的 Word / Excel 文档。

4. `数据上报`
作用：按你设置的“最多可亏损”生成上报建议和上报消息。

5. `设置`
作用：进入设置中心，可修改密码、查看授权、查看套餐、查看版本等。

### 5.2 左侧：客户列表

这里用于管理客户。

你可以：

1. 添加客户。
2. 搜索客户。
3. 切换当前客户。
4. 在单人 / 多人 / 全部 之间切换统计范围。

### 5.3 中间右侧：结果总览与原始消息

这里包含两块非常重要的区域。

1. `结果总览`
内容包括：
   - 查看区域切换
   - 统计范围切换
   - 区域结果汇总
   - 号码累计排行

2. `原始消息`
内容包括：
   - 当前范围内已保存的原始消息
   - 搜索框
   - 高亮命中搜索词
   - 原始消息的编辑、删除、重算

### 5.4 最右侧：号码总览

这里会把当前范围内的号码 / 生肖累计结果做成可视化卡片，方便快速看热点。

## 6. 第一次上手，推荐这样操作

如果你是第一次用，建议严格按下面顺序走一遍：

1. 添加一个客户。
2. 选中这个客户。
3. 点击 `消息识别`。
4. 在弹窗中选择录入区域。
5. 粘贴一条原始消息。
6. 先看右侧 `识别核对` 是否正常。
7. 没问题再点 `添加`。
8. 回到主界面，看 `号码累计排行`、`原始消息`、`号码总览` 是否同步更新。
9. 在 `结果总览` 输入中奖号，查看区域结果汇总。
10. 需要发给别人时，再用 `复制当前范围` 或 `导出当前范围`。

这是最稳妥的流程。不要一上来就大批量导入。

## 7. 客户管理详细说明

### 7.1 添加客户

操作：

1. 在左侧 `输入新客户名称` 输入名字。
2. 点击 `添加客户`。

系统默认会给新客户带上结算参数：

1. `倍率 = 47`
2. `返利 = 4`

如果这个客户需要不同的结算参数，添加后请及时修改。

### 7.2 搜索客户

在 `搜索客户名称` 输入关键字，列表会实时筛选。

### 7.3 统计范围

在主界面上方可以切换 3 种范围：

1. `单人`
只看当前选中的一个客户。

2. `多人`
同时看你勾选或选中的多个客户。

3. `全部`
查看当前所有客户合计结果。

建议：

1. 日常录入时用 `单人`。
2. 查多个客户对比时用 `多人`。
3. 做全盘查看时用 `全部`。

### 7.4 查看区域

系统支持按区域查看数据。  
界面上可以切换：

1. 新奥
2. 老奥
3. 香港

查看区域只影响当前你看到的统计视图，不会改写已经保存的数据。

## 8. 消息识别弹窗，逐项怎么用

点击顶部 `消息识别` 后，会打开录入弹窗。

这个弹窗分成 3 列：

1. 左列：原始消息输入与辅助功能
2. 中列：识别核对
3. 右列：规则与属性面板

### 8.1 左列第 1 行：录入区域

这里决定本次录入默认归到哪个区域。

常见做法：

1. 如果整条消息都属于同一个区域，直接在这里选一次。
2. 如果原始消息里本身写了新奥 / 老奥 / 香港，解析器也会识别区域词。
3. 如果客户被设置为“不分区域统计”，那最终会统一记到客户默认区域。

### 8.2 左列第 2 行：输入提示

这行文案的意思是：

1. 你在左边输入原始消息。
2. 系统会自动解析。
3. 右边会实时显示标准格式和风险提示。

### 8.3 左列核心：消息输入框

这是你最常用的输入框。

支持的使用方式：

1. 手动输入。
2. 从聊天软件直接粘贴。
3. 一次粘贴多行。
4. 录音转文字后自动回填。
5. OCR 识别结果回填。
6. 微信复制监听自动填充。

当前版本下，这个输入框的行为是：

1. 默认会尽量占满左侧剩余空间。
2. 长消息会在框内正常滚动。
3. 粘贴很多内容时，可以滚回顶部检查前面的行。

### 8.4 左列可选功能：语音录入

按钮：`语音录入`

适用场景：

1. 手上不方便打字。
2. 需要快速把口述内容转成文字。

使用方式：

1. 点击 `语音录入`。
2. 对着麦克风说话。
3. 系统停止后会把语音转成文字。
4. 如果套餐支持，还会自动尝试做本地 AI 修正。

注意：

1. 首次使用可能会申请麦克风权限。
2. 录音环境嘈杂时，建议先录短句测试。
3. 语音功能属于 Pro 能力。

### 8.5 左列可选功能：微信自动监听复制

位置：输入框上方蓝色提示框。

功能说明：

1. 打开后，系统会监听你从微信复制的内容。
2. 检测到新内容时，会自动填充到输入框并触发识别预览。
3. 对同一天同一客户的重复消息，会弹出重复提醒。

适合场景：

1. 从微信连续复制多条客户消息。
2. 需要减少手工粘贴和重复录入。

注意：

1. 这是 Pro 能力。
2. 打开监听前，建议先选好客户。
3. 如果弹出“重复内容如下”，请确认是否真的要继续添加。

### 8.6 OCR 图片识别

OCR 区域在输入框下方。

支持方式：

1. 点击 `选择图片` 选文件。
2. 把图片拖进 OCR 区域。
3. 在识别页按 `Ctrl/Cmd+V` 直接粘贴截图。

标准流程：

1. 放入图片。
2. 点击 `识别图片`。
3. 查看候选结果。
4. 点击一条候选内容套用到输入框。
5. 再看右侧识别核对。
6. 最后点 `添加`。

注意：

1. OCR 属于 Pro 能力。
2. 图片内容越清晰，结果越稳定。
3. OCR 结果只是候选，最终仍以你核对后的内容为准。

### 8.7 左列底部按钮

1. `识别预览`
作用：强制刷新一次解析结果。

2. `清空输入`
作用：清空当前输入框内容和当前属性选择。

3. `添加`
作用：把当前识别通过的消息写入当前客户数据。

4. `取消`
作用：关闭弹窗，不保存本次输入。

## 9. 识别核对区怎么判断“能不能加”

中间列标题是 `识别核对`。  
你每次录入时，都要先看这里。

### 9.1 正常可加的情况

如果你看到的是：

1. `安全识别`
2. 有标准格式结果
3. 没有红色阻止提示

那么通常可以点击 `添加`。

### 9.2 需要停下来的情况

如果你看到下面任意一种，先不要直接加：

1. `待人工处理`
2. `当前消息已被拦截`
3. `仅未开放玩法`
4. `部分未识别`
5. 解析器提示有歧义

### 9.3 4 个结果分组分别是什么意思

#### A. 待人工处理

说明：

1. 这部分内容当前属于阻止项。
2. 不会允许你直接保存。
3. 常见原因是：
   - 命中了被拦截的关键词
   - 有待处理行
   - 当前规则判定存在高风险内容

#### B. 已识别但未统计

说明：

1. 系统认出来了。
2. 但这类内容不会进入号码统计。
3. 通常用于未开放玩法的提示展示。

#### C. 已忽略

说明：

1. 这部分被判定为噪音、摘要尾巴或无需入账内容。
2. 不影响本次有效统计。

#### D. 安全识别

说明：

1. 这部分已经成功转换成标准格式。
2. 点 `添加` 后会真正入账。

### 9.4 歧义选择弹窗

如果系统无法确定你这句话到底该按哪种规则理解，会弹出 `歧义选择`。

处理方法：

1. 看每个选项的说明。
2. 选择最符合原意的一项。
3. 点击 `确定并改写原文`。

系统会按你选择的方式重写消息，然后继续解析。

## 10. 右侧规则面板，分别是干什么的

右侧规则面板不是每个用户都要天天改。  
但管理员或熟练录入员最好理解这些模块。

### 10.1 号码属性

这里用于维护“号码属性库”。

你可以：

1. 新增自定义属性。
2. 编辑已有属性。
3. 调整属性词叠加策略。

适用场景：

1. 客户有自定义分组。
2. 需要把一组号码取一个固定名字。

### 10.2 属性词叠加策略

可选模式包括：

1. 先交集，空则并集
2. 仅交集
3. 仅并集
4. 每次确认

什么时候会用到：

当一段消息里同时出现多个属性词，例如“红波的小单”，系统需要知道该怎么组合。

### 10.3 区域统计模式

你可以为全局或客户配置：

1. `按区域区分统计`
2. `不分区域，统一入账`

还可以给新奥 / 老奥 / 香港补充附加别名。

适用场景：

1. 有些客户明确分区域。
2. 有些客户虽然消息里写了区域词，但你希望都统一记到某一个区域。

### 10.4 未开放玩法关键词

这里可以补充会被拦截为未开放玩法的关键词。

当前版本下：

1. 平特类关键词会被严格拦截。
2. 命中后会进入阻止态。
3. 不会按普通号码统计放过去。

如果你要增强或收窄拦截范围，可以在这里调整。

### 10.5 消息类型白名单

作用：

把系统允许识别的一些 shorthand 类型显式列出来，你可以选择开或关。

适用场景：

1. 某类简写经常误判。
2. 你希望暂时禁止某一种写法。

### 10.6 金额分配词

作用：

控制某些词命中后，金额是如何分配的。

常见模式有：

1. 每个号码录入金额
2. 每个目标组录入金额
3. 本段总金额平分
4. 未确定，解析时再确认

如果你经常遇到“都买 / 各肖 / 平摊”这类词，这个模块非常关键。

### 10.7 不入账规则

作用：

让系统忽略尾部摘要或无效文字。

典型例子：

1. `共{金额}`
2. `合计{金额}`
3. `总计{金额}`

如果你的原始消息经常带这类尾巴，这里非常有用。

### 10.8 金额单位

作用：

让系统识别金额结尾词。

常见单位包括：

1. 元
2. 块
3. 毛
4. 闷

如果某个客户习惯用特殊单位词，可以补充在这里。

## 11. 原始消息保存后，主界面怎么查看

### 11.1 号码累计排行

这里展示当前范围内每个号码的累计值排序。

适合用来：

1. 看高频号码。
2. 快速比较当前范围内哪些号码最多。

### 11.2 区域结果汇总

这里是每天使用频率非常高的区域结算区。

操作：

1. 在区域结果汇总面板里给新奥 / 老奥 / 香港输入中奖号。
2. 输入格式必须是 `01-49`。
3. 输入后系统会自动计算：
   - 当前总注
   - 当前命中
   - 当前结果支出
   - 当前返利
   - 结果汇总

结果口径为：

`结果汇总 = 总注 - 结果支出 - 返利`

说明：

1. 每个客户按自己的倍率和返利参与结算。
2. 如果某区域中奖号未填，该区域只显示总注与返利趋势，不算最终结果。
3. 如果中奖号无效，会提示修正。

### 11.3 原始消息列表

这里会按当前统计范围列出原始消息。

你可以：

1. 搜索原始消息。
2. 查看某条消息属于哪个客户、哪个区域。
3. 编辑原始消息后自动重算。
4. 删除原始消息后自动重算。

建议：

1. 发现统计不对时，先回原始消息列表定位问题。
2. 先改原始消息，再看右侧排行是否同步变化。

### 11.4 号码总览

这里是当前范围的号码卡片视图。

适合：

1. 快速扫一眼大盘。
2. 看号码与生肖的直观累计情况。

## 12. 导出、复制、上报，分别怎么用

### 12.1 复制当前范围

用途：

1. 快速复制一份纯文本结果。
2. 发给同事、群、客户或留档。

建议：

1. 先确认当前统计范围是不是你想要的。
2. 再点复制，避免复制错范围。

### 12.2 导出当前范围

点击后会让你选择导出格式：

1. `Excel`
2. `Word`

导出文档通常包含这些内容：

1. 导出范围
2. 客户列表
3. 查看区域
4. 当前范围总注
5. 中奖号
6. 区域结果汇总
7. 客户注额分布
8. 按金额聚合
9. 号码明细
10. 原始消息结算明细

### 12.3 原始消息结算明细里有什么

当前版本导出时，原始消息结算明细会带这些字段：

1. 序号
2. 客户
3. 区域
4. 中奖号
5. 结果状态
6. 本条总注
7. 本条命中
8. 结算倍率
9. 本条返利
10. 本条结果支出
11. 本条结果
12. 内容

其中 `本条命中` 的含义是：

在当前中奖号下，这条原始消息命中的那部分金额。

### 12.4 数据上报

`数据上报` 弹窗适合做“给上级或对接方发建议方案”。

使用方式：

1. 输入 `最多可亏损`。
2. 点击 `计算并生成`。
3. 看系统给出的建议行。
4. 需要发送时点 `复制上报消息`。

注意：

1. 这是基于当前范围和当前规则计算的建议。
2. 使用前请先确认当前统计范围、区域和客户是否正确。

## 13. 设置中心怎么用

点击右上角 `设置` 可进入设置中心。

### 13.1 修改密码

需要填写：

1. 当前密码
2. 新密码
3. 确认新密码

要求：

1. 新密码至少 4 位。

### 13.2 版本号

这里会显示当前软件版本。  
用户反馈问题时，一定要把这个版本号一起发出来。

### 13.3 套餐升级

这里可以查看当前套餐与升级说明。

### 13.4 授权管理

这里用于：

## 14. 授权管理详细说明

授权管理弹窗里通常会显示这些字段：

1. 客户编号
2. 授权模式
3. 到期时间
4. 宽限剩余
5. 授权 U 盘路径
6. 授权文件路径
7. 离线授权设备码
8. 状态说明
9. 上次刷新

### 14.1 授权模式有哪些

一般有两种：

1. `U盘授权`
2. `离线授权`

### 14.2 U 盘授权怎么确认正常

你应该检查：

1. 授权模式显示为 U 盘授权。
2. 授权 U 盘路径不是空。
3. 状态说明显示有效。

### 14.3 离线授权怎么激活

有两种常见方式：

#### 方式 A：复制离线授权信息给管理员

1. 打开授权管理。
2. 点击 `复制离线授权信息`。
3. 发给管理员。
4. 管理员返回授权码或 `license.dat` 内容。

#### 方式 B：粘贴授权码激活

1. 把管理员发来的授权码或完整 `license.dat` 内容复制好。
2. 粘贴到 `授权码激活` 文本框。
3. 点击 `激活授权码`。
4. 点击 `刷新状态`。
5. 确认状态变成有效。

### 14.4 什么时候要点“刷新状态”

下面这些情况都建议手动点一次：

1. 刚插入授权 U 盘。
2. 刚粘贴激活授权码。
3. 更换了授权文件。
4. 软件刚提示授权异常。

## 15. Plus 与 Pro 的区别

### 15.1 Plus 适合谁

适合：

1. 主要靠手工录入。
2. 核心需求是解析、统计、导出。
3. 不依赖 OCR、语音、微信复制监听。

### 15.2 Pro 多了什么

Pro 在 Plus 基础上增加：

1. OCR 图片识别
2. 语音录入
3. 本地 AI 语义修正
4. 微信自动监听复制
5. 持续更新能力

如果你日常高频录入、截图录入、语音录入很多，建议使用 Pro。

## 16. 每天最推荐的使用顺序

建议你每天按下面顺序操作：

1. 启动软件前，先确认授权 U 盘是否插好。
2. 打开软件，先看是否能正常进入主界面。
3. 先选好客户和统计范围。
4. 先录入 1 条样例消息确认规则正常。
5. 再开始批量录入。
6. 录完后输入中奖号，检查区域结果汇总。
7. 抽查 2 到 3 条原始消息是否和统计一致。
8. 最后再复制或导出。

不要颠倒成“先导出，后检查”。

## 17. 常见问题与处理办法

### 17.1 打不开软件

处理顺序：

1. 重启电脑。
2. 再次打开软件。
3. Windows 可尝试右键管理员身份运行。
4. 仍然不行就联系管理员。

### 17.2 提示未授权 / 授权失效

处理顺序：

1. 如果是 U 盘授权，确认 U 盘是否已插入。
2. 打开 `授权管理`。
3. 点击 `刷新状态`。
4. 如果还是失败，复制离线授权信息给管理员。

### 17.3 粘贴授权信息时提示失败

当前版本已经做了剪贴板兜底。  
如果仍然失败：

1. 先关闭后重开软件。
2. 再重试一次。
3. 如果还是不行，截图发给管理员。

### 17.4 长消息看不全 / 滚不动

当前版本已把识别页输入框改成：

1. 默认尽量高。
2. 长消息框内滚动。

如果你仍遇到看不全：

1. 先关闭识别弹窗再重新打开。
2. 再粘贴一次。
3. 如果依旧异常，附带截图反馈。

### 17.5 识别预览出现红色拦截

常见原因：

1. 命中未开放玩法关键词。
2. 仍有待人工处理内容。
3. 当前消息存在高风险写法。

处理建议：

1. 先看红色区域提示原因。
2. 必要时修改原始消息表达。
3. 再重新预览。

### 17.6 中奖号输入后结果不对

优先检查：

1. 中奖号是否是 `01-49`。
2. 当前查看区域是否正确。
3. 当前统计范围是否正确。
4. 客户倍率和返利是否配置正确。
5. 是否有原始消息录到了错误区域。

### 17.7 导出失败

处理顺序：

1. 确认当前范围下确实有数据。
2. 确认导出目录可写。
3. 文件没有被 Excel / WPS 占用。
4. 再重新导出。

### 17.8 原始消息编辑后没变化

请确认：

1. 你点的是 `保存`，不是 `取消`。
2. 编辑后的内容能通过预览解析。
3. 当前查看范围包含这条消息所在客户。
