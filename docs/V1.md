# MessageCounter V1 需求说明

## 1. 目标
V1 目标是交付一个稳定可用的本地桌面工具，用于管理多名网友的消息数据，并完成号码/生肖累计统计与汇总。

## 2. 用户场景
1. 用户新增或切换网友。
2. 粘贴一条消息（如 `14.21.13～各20`）进行识别。
3. 确认后写入该网友统计。
4. 查看当前网友排序，或切换“所有网友汇总”查看总览。
5. 删除某条原始记录时，系统可正确回滚统计。

## 3. V1 范围（In Scope）
1. 用户管理：新增、删除、切换。
2. 消息识别：
   - 支持格式：`数字分隔串～各金额`、`数字分隔串~各金额`。
   - 数字分隔符支持：`.`、空格、`,`、`，`、`-`、`—`、`/`。
3. 数据统计：
   - 当前网友：号码与生肖累计值、排序展示。
   - 全部网友：汇总展示与排序。
4. 原始记录管理：
   - 保留每次输入原文。
   - 删除原文后自动重算该网友统计。
5. 数据持久化：
   - 本地文件保存/读取用户数据。
   - 应用重启后数据可恢复。

## 4. 非范围（Out of Scope）
1. 试用期限制与授权控制。
2. 远程同步、登录系统、多端共享。
3. 自动更新与签名发布流程优化。
4. UI 主题重构与复杂动效。

## 5. 关键规则
1. 合法号码范围：`01-49`。
2. 金额必须为正整数。
3. 单条消息内可出现多个号码，金额按“各X”叠加到每个号码。
4. 用户总计值 `totalCount` 为该用户全部号码 `value` 之和。
5. 任意重算后需保证：
   - `totalCount` 与明细一致。
   - 不出现负值。

## 6. 验收标准（V1）
1. 新增用户后，列表和详情区域即时更新，重启后仍存在。
2. 输入 `14.21.13～各20`，确认后：
   - 14/21/13 的累计值各 +20。
   - 总计值 +60。
3. 输入 `14 21 13~各20` 也可成功解析（分隔符兼容）。
4. 删除一条原始记录后，相关号码和总计正确回滚。
5. 点击“所有网友消息汇总”可看到全用户汇总值。
6. 不再出现“试用期已过”拦截页面。

## 7. 开发顺序
1. 稳定核心数据链路：识别 -> 写入 -> 保存 -> 重启恢复。
2. 修复删除原始记录后的重算一致性。
3. 完成汇总与复制导出行为校验。
4. 补充最小回归清单（手工）。
