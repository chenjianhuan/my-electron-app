# MessageCounter 用户使用说明书（V5.0）

适用对象：第一次接触软件的客户、店员、运营同事。

这份文档只讲一件事：你应该点哪里、输入什么、看到什么才算成功。

## 1. 你会拿到什么

1. 安装包（Windows 一般是 `.exe`）。
2. 授权 U 盘（里面有 `license.dat`）。
3. 业务登录密码（A 业务密码、B 业务密码）。

如果你没拿到这 3 样，先不要安装，联系发你软件的人补齐。

## 2. 第一次安装（Windows）

1. 双击安装包，例如 `MessageCounter Setup x.x.x.exe`。
2. 一路点击“下一步/安装”。
3. 安装完成后，桌面会出现软件图标。
4. 不要急着打开，先插入授权 U 盘。
5. 再双击软件图标启动。

成功标志：软件能打开到“请输入访问密码”页面。

## 3. 先做授权检查（非常重要）

每次开软件前，建议先确认 U 盘已插好。

1. 打开软件。
2. 进入 A 业务后，点顶部菜单“授权管理”。
3. 看这三项：
4. `授权模式` 显示 U 盘授权或离线授权。
5. `到期时间` 不是空。
6. `状态说明` 显示有效，不是报错。

如果无效，先看第 10 章“故障排查”。

## 4. 登录与业务入口

启动后会看到“请输入访问密码”。

1. 输入 A 业务密码，进入“客户消息统计（六合彩统计）”。
2. 输入 B 业务密码，进入“微信聊天记录统计”。
3. 忘记密码：联系管理员重发，不要反复乱试。
4. 连续输错太多次会被暂时锁定，等提示秒数结束再试。

## 5. A 业务入门（客户消息统计）

A 业务适合做：客户下注消息录入、统计、汇总、导出。

### 5.1 最短上手流程（3 分钟）

1. 左侧“客户列表”输入客户名，点“添加客户”。
2. 点顶部“识别客户消息”。
3. 在输入框粘贴一条消息。
4. 点“识别预览”。
5. 核对右侧结果没问题后点“添加”。
6. 返回主界面看“累计值排序”和“原始数据列表”。
7. 需要发结果时点“复制客户统计”或“导出统计文档”。

### 5.2 常用按钮说明

1. `识别客户消息`：打开录入弹窗。
2. `所有客户汇总`：切到总览，不只看单个客户。
3. `复制客户统计`：复制当前统计结果到剪贴板。
4. `导出统计文档`：导出文件给别人。
5. `清空客户数据`：删除 A 业务数据，删除后不可恢复。
6. `授权管理`：看授权是否有效。
7. `套餐与升级`：看 Plus/Pro 说明。

### 5.3 OCR 图片识别怎么用（如已开通）

1. 在“识别客户消息”弹窗里，点“选择图片”或直接粘贴截图。
2. 点“识别图片”。
3. 候选结果会显示在下方，点击一条可套用。
4. 再点“识别预览”确认。
5. 最后点“添加”。

## 6. B 业务入门（微信聊天记录统计）

B 业务适合做：微信聊天记录归档、筛选、统计、导出 CSV。

### 6.1 最短上手流程（3 分钟）

1. 点“新建会话”，先建一个会话名。
2. 点“新增消息”可手工录入单条。
3. 或点“粘贴记录”一次性粘贴多条聊天文本。
4. 或点“导入文件”导入 txt/csv/json。
5. 在“结构化预览”检查结果。
6. 点“确认入库”。
7. 切到“统计结果”看趋势和 Top 排名。
8. 点“导出 CSV”导出表格。

### 6.2 页内主要区域

1. `会话列表`：管理不同群/客户会话。
2. `原始记录`：看明细，可按时间筛选。
3. `结构化预览`：导入后先检查再入库。
4. `统计结果`：消息总数、联系人分布、关键词 Top。
5. `实时摘要`：当前会话关键数字。

### 6.3 常用按钮说明

1. `新建会话`：先创建容器再录入。
2. `新增消息`：手工补录单条。
3. `粘贴记录`：批量粘贴文本。
4. `导入文件`：导入 txt/csv/json。
5. `聊天样式`：调整展示样式。
6. `导出 CSV`：导出当前筛选结果。
7. `安全设置`：查看加密状态和清空数据入口。
8. `退出到密码页`：回到登录页面。

## 7. 两种授权方式怎么用

## 7.1 U 盘授权（推荐）

1. 客户电脑插上授权 U 盘。
2. 启动软件。
3. 在“授权管理”里确认状态有效。
4. 使用期间不要拔掉这只 U 盘。

## 7.2 离线授权（不插 U 盘）

1. 客户先把机器指纹发给管理员。
2. 管理员签发 `license.dat` 回传客户。
3. 客户把文件放到授权目录。
4. Windows 路径：`C:\Users\你的用户名\AppData\Roaming\messagecounter\license.dat`。
5. macOS 路径：`/Users/你的用户名/Library/Application Support/messagecounter/license.dat`。
6. 重启软件后在“授权管理”确认生效。

## 8. 注意事项（必须看）

1. 不要修改授权文件名，必须叫 `license.dat`。
2. 不要把 `license.dat` 放错目录。
3. U 盘授权时，不要中途拔盘。
4. 系统时间不要乱改，时间回拨会触发授权风险检测。
5. “清空客户数据”“清空微信数据”都是不可恢复操作。
6. 导入前先备份重要数据。
7. 不要把软件目录随便改名或移动到受限目录。

## 9. 每日使用建议（防出错）

1. 先插 U 盘，再开软件。
2. 先检查“授权管理”，再开始录入。
3. 大批量导入先用 5 条小样测试。
4. 每天导出一次结果做备份。
5. 下班前确认关键数据已保存。

## 10. 故障排查（按顺序做）

### 10.1 打不开软件

1. 重启电脑。
2. 右键“以管理员身份运行”。
3. 关闭杀毒软件后重试（白名单加入安装目录）。
4. 还不行就重装。

### 10.2 提示未授权或授权失效

1. 确认 U 盘是否是授权那一只。
2. 确认 U 盘根目录是否有 `license.dat`。
3. 打开“授权管理”点“刷新状态”。
4. 重启软件再试。
5. 仍失败就发截图给管理员。

### 10.3 提示密码错误

1. 检查大小写和空格。
2. 不要复制粘贴带空格的密码。
3. 连错被锁定就等倒计时结束。
4. 仍不行联系管理员重发密码。

### 10.4 导出失败

1. 先确认有数据可导出。
2. 选择桌面等可写目录。
3. 文件名不要带特殊字符。
4. 关闭占用该文件的 Excel/WPS 后重试。

## 11. 让客户反馈问题时，必须提供这 5 条

1. 电脑系统版本（Windows/macOS）。
2. 软件版本号（界面右上角或“关于软件”）。
3. 报错截图（完整窗口）。
4. 操作步骤（按 1、2、3 写清楚）。
5. 是否插着授权 U 盘。

## 12. 一句话总结

先授权、再登录、先小量测试、确认无误再批量录入、每天导出备份。
